## AI Usage

An AI assistant (Claude) was used for three tasks. The prompts below are short, since they were given one file at a time.

**1. Code review**
> Do a code review of CheckoutSession, CheckoutView, CartView in Book/views.py. Find issues and show the fixed code.

Result: `AI_REVIEW.md` — original code, notes, final code.

**2. Model tests**
> Write tests for the Book, Category, Order, OrderItem models in Book/models.py. Add a comment in each test saying it was generated by AI.

Result: `Book/tests/test_models.py`, all tests pass, model coverage — 100%.

**3. Docstrings**
> Add docstrings to all views in Book/views.py, payments/views.py, users/views.py. Briefly describe: what the view does, what it accepts, what it returns. If you spot a bug, note it separately, don't touch the code.

Result: docstrings added to all views. AI also flagged (without changing code):
- `BookCreateView/UpdateView/DeleteView` — no permission checks
- `cart_view` — duplicates `CartView`, breaks with multiple books in the cart
- `order_detail_view` — doesn't check that the order belongs to the current user
- `WebhookView` — `webhook_secret` is a hardcoded placeholder
- `logout_view` — logs the username after `logout()`, when it's already empty

All AI output was reviewed manually before being applied.
